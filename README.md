# 🗡️ Pixel Dungeon Crawler 🗡️

Увлекательная 2D roguelike игра с детализированной пиксель-арт графикой! Исследуйте процедурно генерируемые подземелья, сражайтесь с врагами и собирайте сокровища!

## 🎮 Особенности игры

### 🏰 Процедурная генерация подземелий
- Каждое подземелье генерируется случайным образом
- Комнаты соединены коридорами
- Найдите лестницу, чтобы спуститься глубже!

### ⚔️ Боевая система
- Атакуйте врагов мечом (пробел)
- Система прокачки персонажа
- Улучшайте оружие и броню

### 👾 Враги с AI
- **Гоблины** - быстрые и слабые
- **Скелеты** - средней силы
- **Демоны** - мощные и опасные
- Враги преследуют игрока и атакуют

### 💎 Предметы и сокровища
- **Золото** 💰 - валюта подземелий
- **Зелья здоровья** ❤️ - восстанавливают HP
- **Ключи** 🔑 - открывают двери
- **Драгоценные камни** 💎 - дают много очков
- **Мечи** 🗡️ - увеличивают урон
- **Щиты** 🛡️ - улучшают защиту

### 📊 Система прогрессии
- Система уровней и опыта
- Увеличение характеристик при повышении уровня
- Счет и рейтинг
- Глубже = сложнее!

## 🎯 Управление

- **WASD / Стрелки** - Передвижение
- **Пробел** - Атака
- **E** - Взаимодействие (спуститься по лестнице)
- **R** - Перезапустить игру

## 🎨 Графика

Игра использует детализированную пиксель-арт графику с:
- Красочными спрайтами персонажей
- Атмосферными подземельями
- Анимированными врагами
- Эффектами частиц
- Ретро шрифтом "Press Start 2P"

## 🚀 Запуск игры

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build
```

## 🛠️ Технологии

- **React** + **TypeScript** - UI фреймворк
- **Canvas API** - рендеринг графики
- **Vite** - сборщик и dev сервер
- Собственный игровой движок

## 🎪 Игровые механики

- Плавное пиксельное движение
- Определение столкновений
- Система камеры, следующая за игроком
- Анимация атак и движения
- Система частиц для эффектов
- Генерация уровней с комнатами и коридорами

## 📝 Архитектура

```
game/
├── GameEngine.ts    - Главный игровой цикл
├── Player.ts        - Логика игрока
├── Enemy.ts         - AI и поведение врагов
├── Dungeon.ts       - Процедурная генерация уровней
├── Item.ts          - Система предметов
├── Particle.ts      - Система частиц
└── PixelRenderer.ts - Рендеринг пиксель-арт графики
```
